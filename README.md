# PokéPicker

A simple web app to pick a random Pokémon.

## What it does

PokéPicker shows you a random Pokémon with its image, name, number, and types.

You can choose:
- **Mode:** "Up to" picks from generations 1 to the selected one. "Only" picks from that generation range.
- **Generation:** From Generation 1 to Generation 9.

## How to use

1. Open `src/index.html` in your browser.
2. Click the settings button (⚙️).
3. Choose a mode and generation.
4. Click Save.
5. Click anywhere on the main area to get a new random Pokémon.

## Files

- `src/index.html` - main page
- `src/style.css` - styles
- `src/js/pokepicker.js` - picks the Pokémon
- `src/js/settingsModal.js` - settings panel
- `src/js/scoreboard.js` - scoreboard
