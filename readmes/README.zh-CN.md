# PokéPicker

一个用于随机挑选宝可梦的简单网页应用。

## 它能做什么

PokéPicker 会随机显示一只宝可梦，包括图片、名字、编号和类型。

你可以选择：
- **模式：**“直到”会从第 1 代选择到所选代数。“仅限”会从所选代数范围内选择。
- **代数：** 第 1 代到第 9 代。

## 如何使用

1. 在浏览器中打开 `src/index.html`。
2. 点击设置按钮（⚙️）。
3. 选择模式和代数。
4. 点击保存。
5. 点击主区域随机生成一只新宝可梦。

## 文件

- `src/index.html` - 主页面
- `src/style.css` - 样式
- `src/js/pokepicker.js` - 选择宝可梦
- `src/js/settingsModal.js` - 设置面板
- `src/js/scoreboard.js` - 排行榜
