# PokéPicker

ランダムなポケモンを選べるシンプルなウェブアプリです。

## できること

PokéPickerはランダムなポケモンの画像、名前、番号、タイプを表示します。

選べるもの：
- **モード:** 「〜まで」は1世代から選択した世代まで。「指定」は選択した世代範囲から。
- **世代:** 第1世代から第9世代まで。

## 使い方

1. ブラウザで `src/index.html` を開く。
2. 設定ボタン（⚙️）をクリック。
3. モードと世代を選択。
4. 「Save」をクリック。
5. メインエリアをクリックして新しいランダムポケモンを出す。

## ファイル

- `src/index.html` - メインページ
- `src/style.css` - スタイル
- `src/js/pokepicker.js` - ポケモン選択
- `src/js/settingsModal.js` - 設定パネル
- `src/js/scoreboard.js` - スコアボード
